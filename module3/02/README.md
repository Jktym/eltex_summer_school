# Задание 2: Очереди сообщений System V + сигналы

**Цель:** Разработать программу, реализующую модель "Издатель-Брокер-Подписчик".

## Описание задания

Процесс может быть запущен либо в роли брокера сообщений, либо в роли издателя, либо в роли подписчика. Количество процессов-издателей и подписчиков не ограничено.

*   **Брокер (ключ `-b`):**
    Создает очередь сообщений и считывает из нее сообщения с приоритетом, равным 1. В сообщении указана тема (topic) и его содержимое (payload). Сообщение пересылается получателям (подписчикам), которые заинтересованы в получении сообщений с данной темой. 
    Брокер хранит список `pid` процессов-подписчиков и тем, на которые они подписаны (один может подписаться на несколько тем). Также брокер хранит список процессов-издателей, чтобы можно было уведомить их о завершении работы. 
    *Если уже имеется очередь сообщений (другой процесс запущен в роли брокера), новая программа сообщает об этом и завершается.*

*   **Издатель (ключ `-p`):**
    Отправляет в очередь сообщения с указанной темой (указывается в аргументах запуска). В начале текста сообщения передается строка `send,<pid>,<topic>`. Приоритет исходящего сообщения равен 1. Сообщения вводятся пользователем.

*   **Подписчик (ключ `-s`):**
    Читает сообщения из очереди, приоритет которых равен его `pid`, и выводит на экран информацию о полученном сообщении. 
    Для подписки отправляет сообщение с приоритетом 1 и текстом `subscribe,<pid>,<topic>`. При завершении работы уведомляет брокер сообщением `unsubscribe,<pid>,<topic>`. Список тем задается в аргументах запуска.

**Завершение работы:**
При завершении работы брокера он перестает рассылать сообщения, рассылает процессам сигналы о завершении `SIGINT`, удаляет очередь и завершает работу. Процессы-издатели и подписчики корректно завершаются при получении сигнала или если очередь стала недоступной.

## Структура программы

- `pubsub.c` — основной исходный код, содержащий логику всех трех ролей (брокер, издатель, подписчик) и работу с очередями.
- `Makefile` — файл для автоматизированной сборки программы.
